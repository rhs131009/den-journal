# День

Личный ежедневник: задачи, повторения по дням недели, заметки, прогресс и облачные аккаунты Supabase.

Данные пользователей хранятся в Supabase и ограничены правилами Row Level Security. config.js содержит только публичный publishable key. Серверные секреты и пользовательские записи в репозиторий не входят.

Сайт работает без сборки: index.html, style.css, app.js, accounts.js, config.js.
